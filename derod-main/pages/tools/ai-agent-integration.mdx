# AI Agent Integration

DERO documentation is AI-agent-ready. This page explains the discovery standards implemented and how to register DERO with AI platforms.

<Callout type="info" emoji="🤖">
**Agents are the new browsers.** AI agents can now discover, understand, and interact with DERO blockchain using standardized machine-readable formats.
</Callout>

## Discovery Standards Implemented

### Tier 1: Core Discovery

| Standard | URL | Purpose |
|----------|-----|---------|
| **llms.txt** | [/llms.txt](https://derod.org/llms.txt) | Markdown overview for LLMs explaining DERO's capabilities |
| **OpenAPI 3.1** | [/api/openapi.json](https://derod.org/api/openapi.json) | Machine-readable API specification for JSON-RPC methods |
| **JSON-LD** | (in page `<head>`) | Schema.org structured data (Organization, WebSite, TechArticle) |

### Tier 2: Platform Integration

| Standard | URL | Platform |
|----------|-----|----------|
| **ai-plugin.json** | [/.well-known/ai-plugin.json](https://derod.org/.well-known/ai-plugin.json) | ChatGPT / GPT Actions |
| **agentroot.json** | [/.well-known/agentroot.json](https://derod.org/.well-known/agentroot.json) | Doma AgentRoot (DNS-native discovery) |
| **services.json** | [/.well-known/services.json](https://derod.org/.well-known/services.json) | Schema.org ItemList of services |

## What AI Agents Can Do

With these standards in place, AI agents can:

1. **Discover DERO** — Find the documentation via llms.txt or AgentRoot
2. **Understand the API** — Parse OpenAPI spec to learn JSON-RPC methods
3. **Build queries** — Construct valid RPC calls to daemon/wallet endpoints
4. **Execute transactions** — Help users interact with smart contracts
5. **Answer questions** — Provide accurate information about DERO privacy features

## Registry Submission Guide

### 1. MCP Registry (Anthropic)

The Model Context Protocol (MCP) allows Claude and other agents to access DERO data.

**Status:** DERO doesn't run an MCP server (the RPC APIs run on blockchain nodes, not the docs site), but agents can use the OpenAPI spec to understand how to call DERO nodes.

**For full MCP integration:**
- Build an MCP server that wraps DERO RPC calls
- Register at: [modelcontextprotocol.io](https://modelcontextprotocol.io)
- See MCP spec: [github.com/anthropics/anthropic-tools](https://github.com/anthropics/anthropic-tools)

### 2. mcp.so

Community MCP directory.

**Submission:**
1. Go to [mcp.so](https://mcp.so)
2. Click "Submit Server"
3. Provide:
   - Name: `DERO Blockchain`
   - Description: `Privacy blockchain with homomorphic encryption`
   - Repository URL: `https://github.com/deroproject/derohe`
   - Documentation: `https://derod.org`

### 3. Smithery.ai

AI tool marketplace.

**Submission:**
1. Visit [smithery.ai](https://smithery.ai)
2. Create account and click "Add Tool"
3. Provide OpenAPI spec URL: `https://derod.org/api/openapi.json`
4. Follow verification steps

### 4. Glama.ai

AI agent directory.

**Submission:**
1. Go to [glama.ai](https://glama.ai)
2. Submit your AgentRoot URL: `https://derod.org/.well-known/agentroot.json`
3. Provide llms.txt URL: `https://derod.org/llms.txt`

### 5. OpenAI GPT Store

Create a Custom GPT that uses DERO's API.

**Steps:**
1. Go to [chat.openai.com/gpts/editor](https://chat.openai.com/gpts/editor)
2. Create new GPT
3. In "Configure" → "Actions", add:
   - Import from URL: `https://derod.org/api/openapi.json`
4. Name: `DERO Blockchain Assistant`
5. Description: `Query DERO blockchain, check smart contracts, and learn about privacy technology`
6. Submit for review

### 6. Google Gemini Extensions

**Status:** Google Gemini extensions require direct partnership. The `gemini-extension.json` format follows similar patterns to ai-plugin.json.

## DNS TXT Records (Optional)

For DNS-native discovery with AgentRoot, add these TXT records:

```
_agentroot.derod.org  TXT  "v=ar1 url=https://derod.org/.well-known/agentroot.json"
_llms.derod.org       TXT  "v=1 url=https://derod.org/llms.txt"
```

## Testing Your Integration

### Verify llms.txt

```bash
curl https://derod.org/llms.txt
```

### Verify OpenAPI Spec

```bash
curl https://derod.org/api/openapi.json | jq '.info'
```

### Verify AI Plugin

```bash
curl https://derod.org/.well-known/ai-plugin.json | jq '.'
```

### Test with an AI Agent

Ask an AI assistant:
> "Using the DERO API, how do I query the current blockchain height?"

It should be able to construct:
```bash
curl -X POST http://node.dero.io:10102/json_rpc \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":"1","method":"DERO.GetHeight"}'
```

## JSON-LD Structured Data

Every page includes Schema.org structured data:

```json
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "Organization",
      "name": "DERO Foundation",
      "url": "https://derofoundation.org"
    },
    {
      "@type": "WebSite", 
      "name": "DERO Documentation",
      "url": "https://derod.org"
    },
    {
      "@type": "TechArticle",
      "headline": "[Page Title]",
      "description": "[Page Description]"
    }
  ]
}
```

## Keeping Standards Updated

When DERO releases new RPC methods:

1. Update `/public/api/openapi.json` with new method schemas
2. Update `/public/llms.txt` if major features change
3. Update `agentroot.json` capabilities list if needed
4. Bump `updated_at` timestamp in agentroot.json
