# HOLOGRAM

The **native desktop browser** for the DERO decentralized web. Immutable content. Zero tracking. Complete privacy.

**220+ API Methods** | **24 Functional Areas** | **3 Platforms**

[Get Started →](/quick-start)

## What Makes Hologram Different?

| Feature | Hologram | Traditional Browsers |
|---------|----------|---------------------|
| Content Source | Blockchain (immutable) | Web servers (mutable) |
| Censorship Resistance | Complete | None |
| Privacy | No tracking | Cookies, trackers |
| Offline Access | Full caching | Limited |
| Native Performance | Desktop app | Browser sandbox |
| Integrated Wallet | Built-in | Extensions required |
| Visual Identity | Villager avatars | Profile pictures |
| Developer Support | EPOCH (passive) | Not available |
| dApp Bridge | telaHost API | Extensions required |
